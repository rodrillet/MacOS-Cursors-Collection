# Colección de cursores de macOS (Mousecape)
- Cursores favoritos de terceros
- Mis dumps de cursores nativos de macOS 

> Todos los créditos pertenecen a sus respectivos autores.

## Conjuntos adicionados em setembro de 2026

- `Dumps nativos do Windows/`: capes para **Windows 8.1, 10 e 11**, convertidos de arquivos `.cur` e `.ani` publicados como extrações de `%WINDIR%\Cursors` em [windows-ui-assets](https://github.com/bartekl1/windows-ui-assets/tree/21970f48b8f66b4d44742cb30388c1454512d681/Cursors). A conversão usou o código do [win2cape](https://github.com/vladimiralbrekhtccr/win2cape/tree/e1d31a2395c75ddefe644311920c9ddbf0269632), selecionando a representação de 32 px para tamanho normal e a de 64 px para telas Retina.
- `Meus capes pessoais/`: cópias dos capes pessoais instalados no meu Mousecape e que ainda não estavam nesta coleção.

Os arquivos selecionados de Windows 10 e 11 nesse acervo são idênticos; os dois capes foram mantidos com nomes separados para facilitar a escolha. **Windows 8.1 não é Windows 8**: ainda não encontrei uma fonte verificável dos cursores originais do Windows 8, por isso não há um cape rotulado como Windows 8.

Os cursores da Microsoft continuam sujeitos aos direitos da Microsoft; a conversão para Mousecape não muda a autoria nem a licença dos desenhos.

Também adicionei `Favoritos de terceros/bibata-modern-ice.cape`, versão Mousecape do [Bibata Cursor](https://github.com/ful1e5/Bibata_Cursor/tree/ddb09273cde49faeb6a32282660ff4293f52d6e0) publicada por [wirenux](https://github.com/wirenux/Bibata-Mouse-Cape/tree/f4ba0fd9c7828e31ea21328dfc1b8d8209a1e0c1). O projeto original tem licença GPL-3.0; a cópia da licença acompanha o cape na mesma pasta.
